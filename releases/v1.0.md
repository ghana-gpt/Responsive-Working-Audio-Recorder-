# Audio Recorder v1.0

**Release type:** Baseline release snapshot  
**Source commit:** `248b39907aab07830810388006d707d1a05d5c08`  
**Source branch:** [`v1.0`](https://github.com/ghana-gpt/Responsive-Working-Audio-Recorder-/tree/v1.0)

## Summary

A responsive, accessible, offline-capable audio recorder that runs entirely in the browser. Recordings stay in the user's browser storage; the app has no backend, accounts, analytics, or upload service.

## Included

- Record, pause, resume, and stop with browser-supported MediaRecorder formats and live microphone metering.
- Store recordings locally in IndexedDB with an in-memory repository cache.
- Search and sort recordings; rename, tag, select, play, delete, download, and share them.
- Import audio files, export recordings individually or as a ZIP, and trim or convert audio to WAV.
- Installable/offline PWA shell with service-worker caching and update notification.
- English and French UI, system/light/dark themes, responsive layout, and accessibility-oriented semantics and keyboard behavior.
- Automated validation, unit tests, Chromium e2e testing, and GitHub Pages deployment workflow.

## Known limitations

- Local browser storage is not a backup or cross-device sync service. Export important recordings separately.
- Large libraries, long WAV conversions/trims, and large ZIP exports can use substantial memory and processing time.
- Automated browser e2e coverage is centered on Chromium; manually validate target browsers and devices.

## Verification

The repository's documented verification command is `npm run verify` (after `npm ci`). The release process should run it on the exact commit being tagged and perform manual tests on the intended browsers/devices.
